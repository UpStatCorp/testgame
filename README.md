# Эхо Северных Лесов — 3D Survival / Fantasy MVP

Атмосферная 3D-игра от первого лица в стилизованном low-poly мире: лес, озеро, горы, деревня
с жителями, лесные твари, три вида оружия (включая жезл телекинеза), инвентарь, смена дня и ночи.

Всё создано кодом — **никаких внешних ассетов**: ландшафт, деревья, дома, существа, иконки
предметов, текстуры и звуки генерируются процедурно.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev        # откройте http://localhost:5173
```

Продакшн-сборка: `npm run build && npm run preview` (http://localhost:4173).

Параметры URL:
- `?quality=low` — облегчённая графика (меньше травы/деревьев, без bloom) для слабых GPU;
- `?autostart` — пропустить стартовый экран (используется автотестами).

## Десктопная версия (Windows / Linux / macOS)

Игра упакована в настольное приложение на Electron — обычное окно, без браузера
(Ctrl и другие клавиши больше не перехватываются браузером, **F11** — полный экран).

- **Готовая сборка для Windows:** скачайте `NorthernWoods-Windows-1.0.0.zip` со страницы
  Releases репозитория, распакуйте и запустите `Echoes of the Northern Woods.exe`.
- Установщик `.exe`, портативный `.exe`, Linux AppImage и macOS `.dmg` собирает GitHub Actions
  (workflow *Desktop builds*, вкладка Actions → артефакты).
- Собрать самому:

```bash
npm install
npm run desktop      # запустить как приложение
npm run dist:win     # Windows: установщик + portable .exe в папке release/
npm run dist:linux   # Linux AppImage
npm run dist:mac     # macOS .dmg (на Mac)
```

## Управление

| Клавиша | Действие |
|---|---|
| **W A S D** | движение |
| **Мышь** | осмотр |
| **Space** | прыжок |
| **Shift** | бег (тратит выносливость) |
| **Ctrl** / **C** | присесть (враги хуже замечают) |
| **E** | взаимодействие (подобрать, открыть, поговорить, разжечь, рубить) |
| **ЛКМ** | атака / использовать предмет / телекинез (удерживать) |
| **ПКМ** | аккуратно опустить предмет телекинезом |
| **Колесо** | дистанция телекинеза / переключение слота |
| **1–8** | слоты панели быстрого доступа |
| **TAB** | инвентарь |
| **F1** или **`** | меню разработчика (spawn, время суток, телепорт) |
| **Esc** | пауза / освободить мышь |

> Ctrl+W в браузере закрывает вкладку — поэтому приседание продублировано на **C**.
> В полноэкранном режиме (кнопка в меню паузы) Chromium перехватывает и Ctrl.

## Механики

- **Мир**: процедурный ландшафт 520×520 м (холмы, горный хребет со снегом, озеро и пруд),
  ~1700 деревьев трёх пород, кусты, папоротники, ~100k пучков травы с ветром, цветы, валуны,
  дорожки, деревня из 5 домов (двери открываются, внутри мебель и сундуки), колодец, рынок,
  костры, причал с лодкой, круг рунических камней, дым из труб, облака, светлячки ночью.
- **Атмосфера**: цикл дня и ночи (10 мин), солнце/луна с тенями, небо со звёздами,
  туман, отражающая вода с пеной у берега, bloom, свет костров и окон ночью.
- **Контроллер от первого лица**: ускорение, гравитация, прыжок, бег, приседание, плавание,
  покачивание камеры (отдельное для бега), наклон при стрейфе, «приземление», тряска камеры,
  FOV при беге, коллизии со стенами/деревьями/камнями, ступеньки.
- **Инвентарь** (32 слота, из них 8 — хотбар): стаки, drag & drop, объединение/разделение,
  выбрасывание в мир, использование ПКМ, описание предметов.
- **Оружие**: одноручный меч (быстрые комбо-удары), двуручный меч (медленный широкий удар,
  больше урона и отбрасывания, hit-stop, тряска), жезл телекинеза. Трейлы ударов, искры, звук.
- **Телекинез**: подсветка и аура цели, захват ЛКМ, объект парит перед игроком и следует за
  взглядом, колесо — дистанция, отпускание ЛКМ — бросок. Энергетический луч, частицы,
  свет, гул. Брошенные предметы наносят урон существам.
- **Существа**: жители (имена, блуждание, idle, приветствие, диалоги, подарки, бегство от
  врагов) и лесные твари с машиной состояний IDLE → PATROL → CHASE → ATTACK → DEAD,
  а также крупный «Древний Шатун». Полоски здоровья, лут, респавн популяции (ночью больше).
- **Здоровье**: HP/выносливость, регенерация, лечение у костра, зелья и еда, урон от падения,
  смерть и возрождение.
- **Звук**: процедурный WebAudio (шаги по разным поверхностям, взмахи, удары, магия, гул
  телекинеза, двери, сундуки, костры, птицы днём, сверчки ночью, ветер). Любой звук можно
  заменить файлом: `game.audio.loadSample('swing', 'sounds/swing.ogg')`.

## Архитектура

```
src/
  core/        Game (композиция систем, главный цикл), Input, EventBus, MathUtils (шум, RNG)
  world/       Terrain, Sky, DayNightCycle, Water, Vegetation, Village, Campfire, Props,
               Pickups, Atmosphere, ProceduralModels, Textures, WorldConfig
  physics/     PhysicsWorld — статические коллайдеры (цилиндры/OBB) + динамические тела
  player/      Player (состояние, HP, выносливость), PlayerController, CameraRig
  items/       ItemDatabase, ItemIcons (canvas-иконки), ItemModels (3D-модели)
  inventory/   Inventory
  weapons/     WeaponDefinitions, WeaponSystem, ViewModel (руки и оружие от первого лица)
  combat/      CombatSystem (попадания, урон, снаряды)
  telekinesis/ Telekinesis
  interaction/ InteractionSystem
  entities/    Health, Creature, Villager, ForestCreature, CreatureModels, SpawnSystem
  ui/          UIManager, HUD, InventoryUI, DialogSystem, DebugMenu, styles.css
  audio/       AudioSystem
  effects/     Particles
tests/         smoke.mjs, mechanics.mjs — headless-проверки через Playwright
```
